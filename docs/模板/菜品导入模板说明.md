# 菜品导入模板说明

**文件**：`docs/模板/菜品导入模板.xlsx`
**导入脚本**：`scripts/import-dish-template.py`

## 工作表

| 表 | 填什么 |
|---|---|
| 填写说明 | 规则与组件类型说明 |
| 菜品主表 | 菜品编号、名称、分类、描述、做法、摆盘、保存/复热、图片、状态 |
| 食材明细 | 每道菜的食材、组件类型、每份净重、每 100g 营养、采购信息、价格、过敏原 |
| 调料明细 | 酱汁/油/糖等，按用量计入营养，不参与主料缩放 |
| 出品内容 | 蛋白主料/主食/蔬菜/酱汁油脂重量（公式自动汇总）、摆盘示例、餐盒建议 |
| 营养计算 | 热量/蛋白/碳水/脂肪（公式自动计算）、总重、热量校验、营养点 |

## 公式口径

```
营养 = Σ(净重 ÷ 100 × 每100g营养)
热量校验：|热量 − (蛋白×4 + 碳水×4 + 脂肪×9)| ≤ 热量×5%
```

校验不过会显示「检查」，说明每 100g 数据与宏量对不上，需要修正。

## 导入

```bash
# 只校验
python3 scripts/import-dish-template.py docs/模板/菜品导入模板.xlsx --dry-run

# 导入本地服务
python3 scripts/import-dish-template.py docs/模板/菜品导入模板.xlsx \
  --api http://127.0.0.1:8080 --user admin --password admin123
```

导入会：

1. 按食材名称去重，创建食材（含组件类型与每 100g 营养）；
2. 创建菜品，把「描述 + 做法 + 摆盘」写入菜品描述；
3. 创建菜品版本，BOM = 食材 + 调料，净重与营养用模板结果；
4. 打印每道菜的营养结果，便于核对。

## 组件类型（配餐按此缩放）

| 类型 | 例子 | 缩放规则 |
|---|---|---|
| 蛋白主料 | 鸡胸、牛肉、鱼虾、蛋清 | 跟随蛋白目标 |
| 主食 | 米饭、藜麦、面包 | 跟随碳水目标 |
| 蔬菜 | 西兰花、青菜 | 固定 |
| 油脂 | 橄榄油、坚果 | 跟随脂肪目标 |
| 其他 | 牛奶、酱汁 | 固定量 |

## 已验证示例

模板自带 3 道示例，导入后与模板公式结果一致：

| 菜品 | 重量 | 热量 | 蛋白 | 碳水 | 脂肪 |
|---|---|---|---|---|---|
| 照烧鸡腿饭 | 578g | 698 | 44.8 | 93.0 | 13.2 |
| 三文鱼鸡胸双拼藜麦碗 | 540g | 660 | 53.5 | 63.3 | 20.3 |
| 厚蛋烧全麦吐司 | 338g | 432 | 29.6 | 49.3 | 12.7 |
