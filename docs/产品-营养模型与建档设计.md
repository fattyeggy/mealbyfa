# 营养模型与建档设计（待确认）

**日期**：2026-11-15
**背景**：现有实现「按蛋白目标缩放菜品」，碳水/脂肪没有固定目标；建档页存在但未被强制。
**目标**：先固定客户的三大营养素需求，再让每餐有目标食物量，菜单只作为载体。

---

## 1. 现在哪里不对

| 项 | 现在的实现 | 你要的 |
|---|---|---|
| 蛋白目标 | 按体重 × 目标系数 × 食量系数，**固定** | 固定 ✅ |
| 热量目标 | 算了，但没有校验计划是否达标 | 固定并校验 |
| 碳水/脂肪目标 | **没有目标**，完全由菜品决定 | 固定 |
| 每餐份量 | 按「每餐蛋白目标」缩放菜品 | 按每餐三大营养素目标定份量 |
| 菜单的作用 | 决定吃什么，也间接决定热量/碳水/脂肪 | 只决定吃什么，不决定需求 |

一句话：**蛋白是固定的，但热量、碳水、脂肪在跟着菜单跑。**

---

## 2. 建议的目标模型

### 2.1 每日目标（在客户建档时算一次，之后不随菜单变）

```
BMR  = 10×体重 + 6.25×身高 − 5×年龄 + (男 +5 / 女 −161)      Mifflin-St Jeor
TDEE = BMR × 活动系数                                       久坐 1.2 / 轻 1.375 / 中 1.55 / 高 1.725
热量 = TDEE − 400（减脂） / TDEE（维持） / TDEE + 300（增肌）
蛋白 = 体重 × (减脂 1.8 / 维持 1.5 / 增肌 1.8) × 食量系数
脂肪 = 热量 × 27% ÷ 9
碳水 = (热量 − 蛋白×4 − 脂肪×9) ÷ 4
```

### 2.2 示例（男 / 30 岁 / 178cm / 75kg / 中等活动 / 减脂）

| 项 | 数值 |
|---|---|
| BMR | 1717.5 |
| TDEE | 2662 |
| 每日热量 | **2262 kcal** |
| 蛋白 | **135 g**（540 kcal） |
| 脂肪 | **68 g**（612 kcal，27%） |
| 碳水 | **278 g**（1110 kcal，余量） |

### 2.3 每餐目标（默认 25% / 40% / 35%，可配置）

| 餐次 | 热量 | 蛋白 | 碳水 | 脂肪 |
|---|---|---|---|---|
| 早餐 | 566 | 34 g | 70 g | 17 g |
| 午餐 | 905 | 54 g | 111 g | 27 g |
| 晚餐 | 792 | 47 g | 97 g | 24 g |

> 实际会有取整误差，允许 ±2g 内。

## 3. 菜单怎么配合

1. 菜单只提供「有哪些菜、BOM、成本」；
2. 生成计划时，按**每餐蛋白目标**缩放份量（保持现有营养点与计价口径不变）；
3. 缩放后计算该餐的实际 热量/碳水/脂肪，与目标比较；
4. 偏差阈值（建议）：蛋白 ±5%、热量 ±10%、碳水 ±15%、脂肪 ±20%；
5. 超阈值生成「复核事项」，由运营调整菜品或接受偏差。

### 超阈值怎么处理（需要你选）

| 方案 | 做法 | 影响 |
|---|---|---|
| **A. 只提示**（推荐先做） | 计划照常生成，偏差写入复核，运营处理 | 不改价格逻辑，最快落地 |
| B. 自动调份量贴近热量 | 按热量缩放，蛋白与价格随之变化 | 会改变营养点与日价 |
| C. 允许加主食/配菜补齐 | 新增「加餐/配菜」商品与定价 | 产品与供应链改动最大 |

## 4. Onboarding 设计

### 4.1 为什么你现在没看到

- 首页允许**未登录浏览菜单**（手册 §16 要求）；
- 只有点「获取我的三餐方案」才会跳到建档；
- 已登录但未建档时，首页只是显示按钮，**不会强制跳转**；
- 如果这个微信号之前登录过（建档过），会直接进首页。

### 4.2 建议的门禁

| 用户状态 | 能看什么 |
|---|---|
| 未登录 | 只看公共菜单（本周/下周） |
| 已登录未建档 | 任何个性化页面（首页 CTA/计划/订单/我的）自动跳建档 |
| 已建档未生成计划 | 可看计划页，提示「生成本周计划」 |
| 已建档有计划 | 全部功能 |

### 4.3 建档三步

**第 1 步 · 身体与目标（必填）**

| 字段 | 说明 | 校验 |
|---|---|---|
| 性别 | 男/女 | 必选 |
| 出生日期 | 用于年龄 | 14–80 岁 |
| 身高 | cm | 120–220 |
| 当前体重 | kg | 35–250 |
| 目标体重 | kg（可选） | 与当前体重差 ≤ 30% |
| 活动水平 | 久坐/轻/中/高 | 必选 |
| 目标 | 减脂/维持/增肌 | 必选 |

**第 2 步 · 饮食与限制（必填 + 可跳过项）**

| 字段 | 说明 |
|---|---|
| 食量 | 偏小/正常/偏大（影响蛋白系数） |
| 训练状态 | 如「每周三次力量训练」 |
| 过敏原 | **多选**：花生、坚果、虾蟹、鱼、蛋、奶、麸质、大豆 + 自定义 |
| 忌口食材 | 多选/自定义（如香菜、内脏） |
| 蛋白偏好 | 鸡/牛/鱼/虾/植物（影响替换推荐） |
| 餐次习惯 | 是否吃早餐、是否吃晚餐 |

**第 3 步 · 配送与联系（必填）**

| 字段 | 说明 |
|---|---|
| 联系人 | 必填 |
| 手机号 | 11 位校验 |
| 配送地址 | 必填，保存为默认地址 |
| 期望开始日期 | 默认下周一 |
| 隐私同意 | 勾选后才能提交 |

**完成页**

展示计算结果并让用户确认：

```
你的每日目标
热量 2262 kcal · 蛋白 135g · 碳水 278g · 脂肪 68g
早餐 566 kcal / 午餐 905 kcal / 晚餐 792 kcal
[返回修改]  [确认并生成计划]
```

### 4.4 健康与合规

- 孕期、哺乳、慢性病、医嘱饮食：勾选后提示「建议咨询医生」，可转人工，不自动生成计划；
- 隐私声明：说明身体数据、过敏信息、地址、手机号的用途与保存期限；
- 建档结果可修改，但**已生成的计划与已下的订单不回溯**。

## 6. 验收标准

1. 同一用户在同一周内换菜单，**三大营养素目标不变**，只有实际摄入变化；
2. 未建档用户进不了计划/下单页面；
3. 建档完成页数值与后端一致（取整一致）；
4. 偏差超阈值出现复核事项，处理后放行；
5. 过敏原、忌口在换菜与下单时都能拦截。
