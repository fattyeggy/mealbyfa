# 发发的餐 · 餐的 SOP（试用版 V1.0）

适用范围：小范围试用期，每天 20–50 份，3 道菜（早/午/晚）。
目标：同一份菜单，不同用户按各自克重装盒；生熟不混、过敏原不漏、温度不断。

## 1. 角色

| 角色 | 负责 |
|---|---|
| 运营 | 建档、排周菜单、复核计划偏差、处理订单与售后 |
| 采购 | 按周菜单备货，收货验收 |
| 厨房 | 初加工、烹饪、出成率记录 |
| 分装 | 按分装单称重、贴标、装盒 |
| 配送 | 取餐、保温、按时送达、交接拍照 |

## 2. 时间线

- **D-2**：运营确认下周菜单；系统导出各菜品 BOM 与总克重；采购下单。
- **D-1 上午**：收货验收；初加工；按菜品标准配方备料。
- **D-1 下午**：烹饪；测中心温度；记录出成率；冷却。
- **D-1 晚上**：按订单分装、贴标、冷藏（0–4℃）。
- **D 早上**：早餐配送（前一天晚餐批次一起出）；午餐、晚餐按窗口配送。

## 3. 收货与储存

1. 核对品名、规格、数量、日期；肉类/水产中心温度 ≤ 4℃，冷冻 ≤ -18℃。
2. 生熟分柜：上层熟食、下层生食；荤素分开；先进先出。
3. 拒收：胀袋、异味、温度超标、无标签、临期。
4. 记录：供应商、批次、温度、验收人。

## 4. 初加工与烹饪

1. 按菜品标准配方（模板 BOM）称生重，误差 ±2%。
2. 生熟砧板/刀具分开；过敏原食材（大豆、小麦、蛋、奶、鱼、虾蟹、坚果）单独工具。
3. 烹饪中心温度 ≥ 75℃（禽肉），保持 15 秒；测3点记录。
4. 记录每道菜的**出成率** = 熟重 ÷ 生重；与模板基准偏差超过 5% 要报运营。

## 5. 分装（关键）

1. 系统分装单给的是**熟重**，不是生重；按用户、餐次、菜品三行核对。
2. 蛋白主料、主食、蔬菜、酱汁分格；酱汁单独小盒。
3. 每盒称重误差 ±5g；连续 3 盒超差停机校准。
4. 过敏原：分装前看订单忌口；含过敏原的菜不能靠“挑掉”处理，必须换菜。
5. 装盒后立即贴标、封口、入冷藏。

## 6. 标签

必标：用户昵称/手机号后四位、配送日期、餐次、菜品名、净重（熟重）、过敏原、复热方式、制作日期。
示例：`张三 1234｜11-24 午餐｜照烧鸡胸饭 531g｜含大豆、小麦｜微波 90 秒`

## 7. 配送

1. 冷藏取出后保温箱（0–60℃ 区间外不久留）；早餐与晚餐批次按路线合并。
2. 交接拍照：餐盒数量、标签、封口。
3. 超时 30 分钟联系运营；破漏、错餐立即补送并记录。

## 8. 异常处理

| 异常 | 处理 |
|---|---|
| 食材缺货 | 同组件、同营养替代，运营确认后才可换；不得私自换主食/蛋白 |
| 出成率异常 | 查明原因（火候/注水/批次），更新模板出成率 |
| 过敏原风险 | 立即停发该批次，换菜或退款 |
| 客户投诉 | 2 小时内响应；留样 + 照片 + 订单号 |
| 计划偏差 | 运营在后台复核后放行；未复核不能下单 |

## 9. 留样与清洁

- 每道菜每批留样 125g，冷藏 48 小时，标注日期/餐次。
- 每日收工：台面、砧板、刀具、称、保温箱清洁消毒；垃圾不过夜。
- 每周：冰箱除霜、死角清洁、虫害检查。

## 10. 每日检查清单

- [ ] 收货温度与数量记录
- [ ] 生熟工具分开
- [ ] 中心温度 ≥ 75℃
- [ ] 出成率已记录
- [ ] 分装单与订单数量一致
- [ ] 过敏原核对
- [ ] 标签完整
- [ ] 留样 125g×48h
- [ ] 冷藏 0–4℃
- [ ] 配送交接拍照
