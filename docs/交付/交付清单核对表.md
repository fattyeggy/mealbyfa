## 3. 重新生成

文档 1、4、8 中的接口清单、数据字典、第三方清单均为脚本生成，改代码后重跑即可：

```bash
python3 scripts/gen-delivery-docs.py     # 接口清单 + 数据字典
python3 scripts/gen-third-party.py       # 第三方依赖声明
```
