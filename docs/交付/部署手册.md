# 部署手册

## 1. 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | 后端运行 |
| MySQL | 8.x（或 MariaDB 10.6+） | 生产库；开发可用 H2 |
| Node.js | 18+ | 小程序与后台构建 |
| Nginx | 任意稳定版 | 反向代理与静态托管 |
| 微信小程序 | 已认证主体 + AppID | 小程序发布 |

---

## 2. 快速体验（H2，无需装库）

```bash
cd backend
JAVA_HOME=<jdk17> mvn -DskipTests package
java -jar target/sancan-meal-service.jar          # 8080，自动建 H2 文件库
curl http://127.0.0.1:8080/ping
```

默认写入 `backend/data/`，删掉即可重置。**仅用于开发与演示。**

## 3. 生产部署

### 3.1 数据库

```bash
# 全新库
mysql -u root -p -e "CREATE DATABASE sancan DEFAULT CHARACTER SET utf8mb4;"
mysql -u root -p sancan < backend/src/main/resources/db/schema.sql
mysql -u root -p sancan < backend/src/main/resources/db/mysql-indexes.sql

# 已有库升级（P4 之前的旧库）
mysql -u root -p sancan < backend/src/main/resources/db/migration-p4.5-p4.6-mysql.sql
```

部署前可先自检：

```bash
MYSQL_CLIENT=mysql MYSQL_SOCKET=/tmp/mysql.sock ./scripts/verify-mysql.sh
```

> 该脚本会创建并删除 `sancan_verify` / `sancan_migrate` 两个库，**不要指向生产实例**。

### 3.2 后端

```bash
cd backend
mvn -DskipTests package

export MYSQL_URL="jdbc:mysql://127.0.0.1:3306/sancan?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8&allowPublicKeyRetrieval=true"
export MYSQL_USER=sancan
export MYSQL_PASSWORD='***'

java -jar target/sancan-meal-service.jar \
     --spring.profiles.active=mysql \
     --server.port=8080
```

- `mysql` profile 关闭自动建表（`spring.sql.init.mode=never`），建表与迁移由 DBA 执行；
- 首次启动会创建 4 个默认账号（admin/ops/finance/auditor），**必须立即改密**；
- 健康检查：`GET /ping`；
- 时区必须为 Asia/Shanghai（锁单与「明天」的判断依赖服务器时区）。

### 3.3 小程序

```bash
cd miniapp
npm install

# H5（用于内测预览）
VITE_API_BASE=https://api.example.com npm run build:h5

# 微信小程序
VITE_API_BASE=https://api.example.com npm run build:mp-weixin
```

1. 在 `src/manifest.json` 填入 `mp-weixin.appid`；
2. 产物在 `dist/build/mp-weixin`，用微信开发者工具导入、上传；
3. 微信后台配置服务器域名（request 合法域名）指向 API 域名；
4. 微信登录已接真实 `code2Session`，按环境配置：

   ```bash
   # 本地（不入库的密钥文件，已 gitignore）
   cat > backend/.env.local <<'EOF'
   export WX_APP_ID=wx...
   export WX_APP_SECRET=...
   EOF
   chmod 600 backend/.env.local
   ./scripts/run-local-wx.sh        # H2 + 关闭 mock + 真实微信登录

   # 体验/生产
   WX_APP_ID=... WX_APP_SECRET=...    java -jar target/sancan-meal-service.jar --spring.profiles.active=prod,mysql
   ```

   - `miniapp/src/manifest.json` 的 `mp-weixin.appid` 需与此 AppID 一致；
   - 真机必须使用 **HTTPS 合法域名**（微信后台配置 request 合法域名）；
     本地联调可在微信开发者工具勾选「不校验合法域名」；
   - 凭据自检（不会泄露密钥）：用任意 code 调 `jscode2session`，
     返回 `40029 invalid code` 表示 AppID/Secret 正确，`40125` 表示密钥错误。

### 3.4 运营后台

```bash
cd admin
npm install
VITE_API_BASE=https://api.example.com/admin npm run build
# 产物 dist/，交给 Nginx 托管
```

### 3.5 Nginx 示例

```nginx
server {
    listen 443 ssl http2;
    server_name api.example.com;

    location /admin/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /app/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
    }

    location /ping { proxy_pass http://127.0.0.1:8080; }
}

server {
    listen 443 ssl http2;
    server_name ops.example.com;

    root /var/www/sancan-admin;
    location / { try_files $uri $uri/ /index.html; }
}
```

## 4. 定时任务与时钟

| 任务 | 时间 | 说明 |
|---|---|---|
| 次日锁单 | 每日 12:00 | cron 配置 `meal.scheduling.lock-cron`，可关闭 `lock-enabled` |

- 任务可重复执行，不会重复扣款（行锁 + 状态机 + 账本唯一索引）；
- 失败清单在订单的 `lockFailReason` 与任务返回值中；
- 服务器时钟必须准确，否则「次日」判断会偏移。

---

## 5. 备份与监控建议

| 项 | 建议 |
|---|---|
| 数据库 | 每日全量备份；`meal_wallet_ledger`、`meal_order_snapshot` 单独保留更久 |
| 恢复演练 | 上线前至少做一次「备份 → 新库恢复 → 服务可用」演练 |
| 监控 | `/ping` 探活；锁单失败数、余额负数（不应出现）、支付回调失败（接入后） |
| 日志 | 后端日志按天切分；审计日志表不可删除，建议单独归档 |

---

## 6. 升级与回滚

见 [`测试与回滚.md`](测试与回滚.md)。要点：

- 代码升级：保留上一版 jar，回滚即换回 jar + 重启；
- 数据库升级：先备份；`migration-p4.5-p4.6-mysql.sql` 只加列/加表，**可保留不回滚**；
- 定价回滚：不支持「回退到旧版本」，只能新建版本并发布（手册 §8 的要求）。
