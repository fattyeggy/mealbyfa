### 2.4 MySQL 部署准备（发现自己埋的坑）

准备真机迁移时发现：**`pom.xml` 里根本没有 MySQL 驱动**。也就是说即使给了真实库，服务也连不上——这是「只在 H2 上跑通」的直接后果。

已补：

- `com.mysql:mysql-connector-j`（runtime scope，不影响测试）；
- `application-mysql.yml`：生产库连接与 `spring.sql.init.mode=never`（生产不自动建表）；
- `scripts/verify-mysql.sh`：重建验证库 → 应用全量 schema → 应用索引 → 核对表数量与唯一索引 → 打印启动冒烟命令。

**仍未在真实 MySQL 上执行**：尝试从 MySQL CDN 拉便携版，候选地址均 404。脚本与文档已就绪，缺口保持打开。

## 6. 下一步建议顺序

1. 角色权限（安全前置，影响所有资金操作）；
2. MySQL 真机跑通（决定能否部署）；
3. 导出/打印与完餐反馈（决定运营能否用）；
4. 微信支付（第二阶段）。

按此顺序，前三项完成后即可进入小范围内部运营；支付接入后才具备收费条件。
