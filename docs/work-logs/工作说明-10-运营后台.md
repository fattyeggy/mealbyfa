# 工作说明 10 · 运营后台（P6）

**日期**：2026-11-15
**阶段**：P6 运营后台
**对应手册**：§13 接口与任务清单、§14 权限与后台角色、§6 每周菜单管理、§9 厨房、§10 成本

---

## 1. 阶段目标

把此前「只有 API、没有界面」的能力补齐——菜单发布、复核处理、定价版本、订单、生产、成本、余额。运营不写代码也能跑完一周业务。

---

## 2. 技术选型

| 项 | 选择 |
|---|---|
| 框架 | Vue3 + Vue Router（hash 模式） |
| 组件库 | Element Plus 2.x（中文语言包） |
| 构建 | Vite 5，产物 1.5 MB（未拆分 vendor） |
| 鉴权 | Bearer 令牌存 localStorage，401 自动回登录页 |
| 代理 | 开发态 `/admin` → `127.0.0.1:8080` |

---

## 3. 页面与能力

| 页面 | 关键操作 |
|---|---|
| 登录 | 账号密码登录，默认 `admin/admin123` |
| 每周菜单 | 列表、新建草稿、**发布前检查**（逐项 PASS/FAIL/人工）、发布 |
| 菜单详情 | 7 天 × 3 餐次明细；逐日编辑早/午/晚菜品版本；检查与发布 |
| 复核事项 | 全局待办列表（蛋白越界 / 份量触界 / 价格兜底），填写处理说明后放行 |
| 定价版本 | 新建草稿 → **复核** → **发布**；维护已审核替换选项（审核即冻结成本） |
| 订单 | 状态/服务日筛选、详情、退款、配送批次状态推进 |
| 厨房生产 | 按服务日生成批次、登记产量与领料、查看食材需求 |
| 成本报表 | 三层成本与毛利、成本参数在线调整 |
| 用户与余额 | 查询余额、发放 credit、人工调增调减、流水冲正 |

界面统一了运营动作与规则约束：**发布后不可改、改价必须新建版本、退款按原来源、账本只增不改**。

---

## 4. 为后台补的两个接口

| 接口 | 原因 |
|---|---|
| `GET /admin/meal/reviews` | 之前只有按计划查，运营需要一个全局待办列表 |
| `GET /admin/meal/dishes/versions/options` | 编辑餐次需要「菜品版本下拉」，避免 N+1 调用 |
