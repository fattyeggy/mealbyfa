## 1. 已实现

### 1.1 计算引擎

`NutritionEngine`（无状态纯函数，配置 v1）：

- BMR：Mifflin-St Jeor；填体脂率时用 Katch-McArdle；
- AF = min(1.9, 日常活动基数 + 运动增量 × 强度系数)；
- TDEE → 目标热量（减脂 0.8 / 维持 1.0 / 增肌 1.1）→ 热量下限（女 1200 / 男 1500）→ 增肌上限 TDEE+500 → 取整到 10；
- BMI ≥ 28 时参考体重取 24 × 身高²；
- 蛋白/脂肪按参考体重；碳水填满剩余热量；
- 蛋白档位 80/100/130/160/190：就近归档、差值相等取低档、超端点取端点；
- 保护规则：蛋白上限 2.2g/kg、脂肪下限 0.6g/kg、碳水低于 100g 时逐级回调并打标；
- 拦截：未成年、超 65、孕期、哺乳、肾病、糖尿病、进食障碍、BMI<18.5 减脂；
- 痛风蛋白系数压到 1.6；结果带 flags 与预期周体重变化。

### 1.2 六步建档

`POST /app/onboarding`：

1. 目标（减脂/维持/增肌三张卡片）
2. 基本信息（性别、年龄、身高、体重、体脂率选填）
3. 活动与运动（日常活动；次数为 0 时隐藏运动明细）
4. 健康筛查（多选，“以上皆无”互斥）
5. 饮食偏好 + 订购餐次 + 配送信息 + 隐私授权
6. 结果页（热量、**蛋白档位主指标**、碳水/脂肪、预期变化、免责声明、缺口）

前端：进度条、逐步校验、可返回修改；拦截进入「人工咨询」页；结果页可「修改档案」。

### 1.3 计划与缺口

- 新建档用户生成计划时直接使用**蛋白档位**（老档案仍走原逻辑，互不影响）；
- 计划保存目标热量/脂肪/碳水/档位/配置版本；
- 计划餐次增加碳水、脂肪实际值（按菜品版本 × 缩放系数）；
- `GET /app/onboarding/gap?date=`：缺口 = 全天目标 − 已订餐次实际，负数按 0；缺口 ≤5% 视为达标；
- 结果页展示「还差多少克 + 约几个掌心/拳/汤匙 + 进度条」。
