## 1. 热量上限：保留规则，但不阻止出计划

业务口径是「不要因为总热量太高而不能出计划」，不是取消营养规则本身：

| 项 | 处理 |
|---|---|
| 增肌热量上限（TDEE + 500） | **保留**，作为目标热量规则 |
| 菜单发布检查：热量/重量/蛋白 **低于下限** | 仍阻止发布（菜单不完整） |
| 菜单发布检查：热量/重量/蛋白 **高于上限** | 改为 `MANUAL` 人工确认，**不阻止发布** |
| 单餐重量上限 | 配置 `meal.plan.max-meal-weight-g`，默认 `0` = 不限 |
| 组件缩放范围 | 0.30–2.50，超界生成复核 |

新增 `HighCalorieMenuTest`：3000+ kcal/天的高热量菜单可以发布（状态 MANUAL），
增肌用户仍能生成计划。

引擎 9 项单测、组件化验收用例均通过。

## 2. 菜品导入模板

文件：`docs/模板/菜品导入模板.xlsx`

| 工作表 | 内容 |
|---|---|
| 填写说明 | 字段规则、组件类型说明、导入命令 |
| 菜品主表 | 编号、名称、分类、描述、**做法步骤**、**摆盘说明**、保存、复热、图片、状态 |
| 食材明细 | 食材、**组件类型**、每份净重、每 100g 热量/蛋白/碳水/脂肪、采购单位/换算/可食率/价格、过敏原 |
| 调料明细 | 酱汁/油/糖等用量与营养，单独计入 |
| 出品内容 | 蛋白主料/主食/蔬菜/酱汁油脂重量（公式汇总）、**摆盘示例**、餐盒建议 |
| 营养计算 | 热量/蛋白/碳水/脂肪（公式）、总重、热量校验、营养点 |

公式口径：

```
营养 = Σ(净重 ÷ 100 × 每100g营养)
热量校验：|热量 − (蛋白×4 + 碳水×4 + 脂肪×9)| ≤ 热量×5%
```

模板自带 3 道示例（照烧鸡腿饭、三文鱼鸡胸双拼藜麦碗、厚蛋烧全麦吐司），
打开即能看到自动计算（需 Excel/WPS/Numbers 打开触发公式）。

## 3. 导入脚本

`scripts/import-dish-template.py`：

- 按食材名去重创建食材（含组件类型与每 100g 营养）；
- 创建菜品，把「描述 + 做法 + 摆盘」写入描述；
- 创建菜品版本，BOM = 食材 + 调料；
- 支持 `--dry-run` 只校验。

## 4. 使用流程

1. 在模板里填菜品、食材、调料、做法、摆盘；
2. 看「营养计算」页的热量校验是否为 OK；
3. 运行导入脚本；
4. 在后台把菜品排进周菜单，系统按组件缩放。
