# 工作说明 25 · 后台按手机号直接建档 + 手机号认领

**日期**：2026-11-16
**依据**：委托方「用户只提供微信手机号，后台就能匹配建档」；蛋白系数按运动强度区分
**结论**：后台建档、手机号认领、蛋白系数按强度已可用；126 项测试通过

## 1. 后台建档

- 管理后台新增「会员建档」页（`/members`）；
- 输入手机号 + 目标/性别/年龄/身高/体重/日常活动/运动/健康筛查/餐次；
- 接口 `POST /admin/meal/members/onboard`，按手机号查找：
  - 没有则创建占位会员（openid = `admin_手机号`）；
  - 已有且已绑微信则拒绝，避免覆盖真实用户；
- 复用营养引擎，返回蛋白档位、热量、碳水、脂肪。

## 2. 用户微信认领

- 小程序建档页新增选填手机号（与后台录入一致）；
- 提交前调用 `POST /app/auth/bind-phone`：
  - 找到同手机号的占位会员，把档案、钱包账户与流水、券、订单转到当前微信账号；
  - 删除占位会员；手机号已绑其他微信则拒绝；
- 实测：后台建档 → 新微信用户绑定同手机号 → 档案变为已建档，档位保留。

## 3. 蛋白系数按运动强度

| 目标 | 低 | 中 | 高 |
|---|---|---|---|
| 减脂 | 1.8 | 2.0 | 2.2 |
| 维持 | 1.4 | 1.6 | 1.8 |
| 增肌 | 1.8 | 2.0 | 2.2 |

不运动按中强度基准；日常活动只影响热量系数。
