## 1. 阶段目标

把已跑通的后端能力做成用户能用的界面：未建档看公共菜单、建档后看个人份量、逐餐替换、下单与查看订单。

---

## 2. 技术选型与工程

| 项 | 选择 |
|---|---|
| 框架 | UniApp Vue3（`@dcloudio/*` Vue3 版本，编译器 5.36） |
| 语言 | TypeScript + SFC |
| 构建 | Vite 5，H5 产物 324 KB |
| UI | 全自定义，未使用商城模板；无图片素材，全部用排版与色块表达 |
| 导航 | `navigationStyle: custom` + 自定义 TabBar（避免依赖图标资源） |

接口封装（`src/utils/api.ts`）做了三件小事：H5 走 `/api` 代理避免跨域、令牌过期自动重登一次、演示账号可固定（`VITE_DEMO_CODE`）。

---

## 3. 页面

| 页面 | 内容 |
|---|---|
| 首页 | 未建档：公共周菜单 + 日期 Slide + 「获取我的三餐方案」；已建档：个人克重、营养点、餐价、底部固定「日价 + 基础/加量/补差 + 下单」 |
| 建档 | 性别、生日、身高体重、活动水平、目标、食量、训练状态、过敏原、忌口、蛋白偏好 |
| 计划 | 周视图，逐日展开三餐；「替换」拉起已审核选项，先试算后提交 |
| 记录 | 订单列表与详情，锁单前可取消并退回优惠券 |
| 我的 | 余额（套餐/现金）、档案、可用券、余额流水、切换演示账号 |

### 与计价规则对齐的展示

- 日价 = 基础三餐 66 元 + 加量费 + 替换补差，底部一眼可见；
- 餐价只作为日价拆分出现，**没有**「总重量 × 单价」；
- 替换弹层展示「份量 / 蛋白 / 补差 / 日价前后」四项，确认前就能看到补价或减价；
- 待复核计划在首页与计划页都有提示条。

## 4. 为界面补的后端接口（2 个）

| 接口 | 原因 |
|---|---|
| `GET /app/plan/swap/options` | 小程序需要「可替换选项」列表；此前只有试算接口，没有候选列表 |
| `PlanWeekResp.themeName / region` | 首页 Hero 需要主题名，原计划响应只有日期 |

`GET /app/plan/swap/options` 只返回**已审核**的替换选项，与 `allow-unreviewed-swap=false` 的生产口径一致。

### 5.3 本轮修掉的问题

| 问题 | 原因 | 处理 |
|---|---|---|
| 首屏右侧被裁切 | `view{}` 选择器在 H5 不生效（渲染为 `uni-view`），盒模型未统一 | 改通配 `* { box-sizing: border-box }`，并用 CDP 量 DOM 复核 `scrollWidth == innerWidth` |
| 已登录仍显示「未建档」 | 页面在 `bootstrap()` 完成前渲染，且未监听会话 | 监听 `session.ready / profile` 变化后重载 |
| 首页 Hero 显示「等待发布」 | 计划响应里没有主题名 | 给 `PlanWeekResp` 补 `themeName / region` |
| 计划页首次进入全折叠 | 默认展开逻辑落在主路径，回退到下周时被跳过 | 移到 `finally` 统一处理 |
| 底部按钮遮挡价目 | 价目卡在滚动流里、按钮固定 | 二者合并为底部固定区，滚动区加 210px 留白 |
