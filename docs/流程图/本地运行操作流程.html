发发的餐

LOCAL RUN GUIDE

本地运行操作流程 · 从启动服务到在微信开发者工具里看到页面

1
启动后端服务
终端运行 ./scripts/run-local-wx.sh，看到 Started MealApplication 即启动成功
2
确认服务在线
浏览器打开 http://127.0.0.1:8080/ping，显示 "status":"UP" 表示正常
能打开并看到 UP 吗？
是 · 继续
进入第 3 步
否 · 排查
看终端有没有报错：
端口被占用 / 找不到 Java / 启动异常
3
构建小程序
终端进入 miniapp，运行 npm run build:mp-weixin，出现 DONE Build complete.
4
导入微信开发者工具
选择目录 miniapp/dist/build/mp-weixin，AppID 用 wx03a10b57ddf70e89
5
关闭域名校验
右上角「详情」→「本地设置」→ 勾选
「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」
6
点「编译」
工具栏编译按钮或 Cmd + B，等待模拟器刷新
首页正常显示了吗？
是 · 完成
可以开始体验：
获取方案 → 建档 → 下单
否 · 排查
打开 Console 标签，
把红色报错截图发给开发
手机真机预览：需要手机能访问的地址。电脑的 127.0.0.1 只对本机有效； 手机和电脑连同一 Wi-Fi 时可用电脑局域网 IP，正式体验则需 HTTPS 域名并在小程序后台配置合法域名。
